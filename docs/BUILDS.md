- **들어 있는 것**
  - 내 차례가 오면 주사위가 세 번 꿈틀한다(5초 더 기다리면 한 번 더, 그 뒤엔 멈춤).
  - 굴리기 버튼이 없어지고, 그 자리에 "주사위를 꾹 누르고 밀어 던지세요" 띠가 있다. 무대 가운데(주사위 주변과 그 아래)
    아무 데나 꾹 누르면 주사위가 마구 흔들리고(딸깍 소리 + 진동), 밀면서 떼면 그 방향으로 날아가 무대 벽에 2~3번 튕기며
    (튕길 때 "딱" 소리, 최대 3번) 굴러 1.2~1.6초 안에 제자리에 멈춘다. 그냥 떼면(또는 키보드 Enter) 앞으로 짧게 던진다
    (약 1.1초). 손가락이 무대 밖으로 나가도 던져진다. 더블이면 예전처럼 금빛.
  - 나오는 눈은 언제나 게임 엔진이 정한 값이다. 던지는 방향·세기는 결과와 상관없다(저장 형식도 그대로).
  - Android 앱(캔버스 효과 기본 꺼짐)에서는 캔버스를 쓰지 않고 진짜 주사위 두 개를 움직인다. 웹(캔버스 효과 켜짐)은 던진
    범위만 한 임시 캔버스 한 장에 그린다.
  - 설정 → "굴리기 버튼 보이기"(기본 끔)를 켜면 버튼이 돌아오고 예전처럼 동작한다(패드도 같이 동작).

  - 동작 줄이기 설정에서는 예전처럼 제자리에서 굴린다.

     차례 배너·라운드 글자를 넘지 않는지, 흰 사각형이 보이지 않는지.
  2. 그냥 눌렀다 떼면 앞으로 짧게 던져지는지. 부드러운지(끊기는지).
  3. 설정에서 "굴리기 버튼 보이기"를 켜고 버튼으로 굴려 본다.

## 2026-10-06 빌드: 소유 색 채움 + 튀어나온 건물

- 커밋 `18ca3eb`, GitHub Actions "Android" 실행 37398086076(성공), 아티팩트 `MoneyPoly-0.1.0-20261006-1015-debug`.

제품 책임자 피드백("빨강이 지으면 테두리만 빨갛다. 카드 배경을 빨강으로 채우고, 초록이 사면 칸 전체가 초록. 지은 건물은
카드 밖, 보드 중앙 쪽 여백으로 튀어나오게")에 대한 빌드.

- **들어 있는 것**
  - 소유한 도시·허브 카드 전체가 소유자 색이다. 이름·가격은 색마다 계산한 잉크(그 색의 짙은 그림자색, 4.5:1 이상)로 쓰고,
    도시 그림은 흰 판 위에 있다. 그룹 색 배지는 흰 테두리로 남고, 가격도 계속 보인다. 인수하면 새 주인 색으로 바뀌고,
    매각·파산으로 은행에 돌아가면 빈 칸 모습으로 돌아간다.
  - 건물(현재 레벨의 별장·빌딩·호텔·명소 하나)이 카드 안쪽 가장자리에 서서 70 %가 보드 중앙 쪽으로 튀어나온다. 지붕은 소유자
    색이고 흰 테두리와 그림자가 있다. 명소는 빛이 난다. 크기는 칸 폭의 55/65/75/95 %다. 그 줄에 앉은 사람 기준으로 똑바로
    서고, 고정 화면(사람 1명 + CPU)의 윗줄은 카드 아래에 똑바로 매달린다. 모서리 양옆 건물은 겹치지 않는다.
  - 건설 컷인의 건물이 마지막에 이 건물 자리로 날아와 팝 한다.
  - 무대 아래쪽(차례인 자리 쪽) 여백이 건물 높이만큼 늘었다. 주사위·굴리기 버튼·프롬프트 버튼은 건물에 닿지 않는다.
  - 같은 푸시에 들어간 다른 작업: 주사위 합을 주사위 위 흰 알약 배지로 표시(`f1ff4ef`, `25a99e7`, `91201a9`).
- **검증**: 타입체크, 단위 테스트 602개(새 건물 기하·잉크 대비 테스트 포함), 전체 브라우저 테스트(`release:check -- --web`)
  92개 통과, 웹 빌드 통과. `npm run perf`는 25/28이다. 피크 레이어 19(≤ 20), 게임·타이틀·결과 유휴 0, 마운트 61 ms.
  라운드 2와 같은 세 개는 여전히 미달이다: 프레임 p99 33.3 ms, 33 ms 초과 프레임, 컷인 안 Paint 68/s. 셋 다 이번 변경과 상관없다.
  스크린샷은 1600×1000과 800×450에서 직접 봤다. 실기기 태블릿 확인은 아직 없다.
- **테스트할 때 볼 것**
  1. 내 땅이 내 색으로 꽉 차 보이는지, 8색 모두에서 이름·가격이 읽히는지(특히 노랑·청록).
  2. 건물이 보드 중앙 쪽으로 튀어나와 멀리서도 레벨(별장 < 빌딩 < 호텔 < 명소)이 구분되는지.
  3. 건물이 굴리기 버튼·주사위 근처에 닿지 않는지. 맞은편 줄 가운데 건물이 차례 배너에, 옆줄 건물이 넓은 프롬프트에 가려지는

  4. 건설 컷인 끝에 건물이 제자리로 날아가 팝 하는지.
