# 빌드 기록

GitHub Actions(저장소 → Actions → "Android")가 `main`에 푸시될 때마다 디버그 APK를 만든다. 아티팩트 이름은
`MoneyPoly-<버전>-<날짜>-<시각>-debug`(한국 시간)이다. 이 문서는 사람이 테스트할 빌드에 무엇이 들어 있는지 적는다.

## 2026-10-05 중간 빌드: 머니 컷인 연결

- 기준 커밋: `39d20e5` (그 위에 이 문서 커밋).
- **들어 있는 것**
  - 모든 돈 이벤트가 전체 화면 머니 컷인으로 나온다: 땅 구매, 건설 L1–L4, 무료 업그레이드, 통행료(면제 포함),
    인수, 모두에게 걷기·주기(카드), 월급·보너스·기부금 수령, 세금·기부·보석금, 매각, 파산, 경매 낙찰.
  - 금·은·동 코인 지갑 더미(각 좌석 가장자리), 코인이 빠지고 쌓이는 소리, 플레이어 사이의 돈은 중앙에 모였다가 이동.
  - CPU 손: CPU가 고른 버튼이나 보드 칸을 손이 눌러 보여 준 뒤 실행.
- **아직 없는 것** (병렬 작업 중, 다음 빌드)
  - 기기 성능별 연출 해상도(자동/높음/낮음), 3D 연출 켜기·끄기. 이 빌드는 2D 연출만 쓴다.
- **검증**: 타입체크, 단위 테스트 491개, 웹 빌드 통과. 브라우저 테스트는 머니 컷인·CPU 손·게임 화면·기본 화면
  스펙 26개 모두 통과(전체 e2e는 다음 빌드에서). 실기기 태블릿 확인은 아직 없다.
- **테스트할 때 볼 것**
  1. 내 땅 구매와 건설: 코인이 내 지갑에서 나와 공사 현장으로 가고 건물이 솟는지.
  2. 통행료: 내 코인이 중앙 도시로 모였다가 주인 지갑으로 가는지, 숫자가 코인과 같이 변하는지.
  3. 생일 같은 "모두에게 걷기" 카드: 중앙 금고에 모인 합계가 네 방향으로 보이는지.
  4. CPU 차례: 손이 누르는 버튼과 실제 결정이 같은지.
  5. 흰 박스, 깜빡임, 버벅임이 있는지(있으면 어느 장면인지).
