# 빌드 기록

GitHub Actions(저장소 → Actions → "Android")가 `main`에 푸시될 때마다 디버그 APK를 만든다. 아티팩트 이름은
`MoneyPoly-<버전>-<날짜>-<시각>-debug`(한국 시간)이다. 이 문서는 사람이 테스트할 빌드에 무엇이 들어 있는지 적는다.

## 2026-10-05 중간 빌드: 머니 컷인 연결

- 기준 커밋: `39d20e5` (그 위에 이 문서 커밋).
- **들어 있는 것**
  - 모든 돈 이벤트가 전체 화면 머니 컷인으로 나온다: 땅 구매, 건설 L1–L4, 무료 업그레이드, 통행료(면제 포함),
    인수, 모두에게 걷기·주기(카드), 월급·보너스·기부금 수령, 세금·기부·보석금, 매각, 파산, 경매 낙찰.
  - 금·은·동 코인 지갑 더미(각 좌석 가장자리), 코인이 빠지고 쌓이는 소리, 플레이어 사이의 돈은 중앙에 모였다가 이동.
  - CPU 손: CPU가 고른 버튼이나 보드 칸을 손이 눌러 보여 준 뒤 실행.
- **아직 없는 것** (병렬 작업 중, 다음 빌드)
  - 기기 성능별 연출 해상도(자동/높음/낮음), 3D 연출 켜기·끄기. 이 빌드는 2D 연출만 쓴다.
- **검증**: 타입체크, 단위 테스트 491개, 웹 빌드 통과. 브라우저 테스트는 머니 컷인·CPU 손·게임 화면·기본 화면
  스펙 26개 모두 통과(전체 e2e는 다음 빌드에서). 실기기 태블릿 확인은 아직 없다.
- **테스트할 때 볼 것**
  1. 내 땅 구매와 건설: 코인이 내 지갑에서 나와 공사 현장으로 가고 건물이 솟는지.
  2. 통행료: 내 코인이 중앙 도시로 모였다가 주인 지갑으로 가는지, 숫자가 코인과 같이 변하는지.
  3. 생일 같은 "모두에게 걷기" 카드: 중앙 금고에 모인 합계가 네 방향으로 보이는지.
  4. CPU 차례: 손이 누르는 버튼과 실제 결정이 같은지.
  5. 흰 박스, 깜빡임, 버벅임이 있는지(있으면 어느 장면인지).

## 다음 빌드: 머니 컷인을 천천히, 읽을 수 있게 (2026-10-05)

중간 빌드를 본 피드백("컷인이 너무 빨리 지나가 눈이 못 따라간다")에 대한 빌드.

- **들어 있는 것**
  - 모든 돈 컷인이 **화면에 3초 이상**(보통 속도): 땅 구매 약 4.5초, 건설 약 4.1초, 세금·월급 약 4.1–4.2초, 통행료 약
    4.3–5.0초, 모두에게 걷기 약 4.9초, 면제 약 3.1초. 같은 턴에 같은 종류가 반복되면 짧아지지만 3.1초 아래로는 안 간다.
  - 포즈 → 포즈 비트: 등장(자리 잡음) → 나갈 코인이 떠오르며 반짝임(예비 동작) → 코인이 하나씩 천천히 호를 그리며 이동 →
    결과(건물이 웅크렸다 솟아 착지하며 찌그러짐, 깃발 꽂힘) → 그 다음 금액 명판 → **1초 이상 정지 화면**(작은 반짝임만) →
    0.3초 퇴장. 망치는 뒤로 젖혔다 내리치고, 은행·금고는 부풀거나 떨렸다가 돈을 낸다. 픽사 12원칙 적용표는
    `docs/MONEY-EVENTS.md` §12.
  - 건너뛰기(보드 탭)는 그대로 ×5, 일시정지에 멈춤, 게임 속도 설정이 길이에 반영된다.
- **아직 없는 것**: 기기별 연출 해상도·3D 연출(별도 작업, 이 빌드에는 없음 — 2D만).
- **턴 시간**(이 컨테이너, `e2e/pacing.spec.ts`): CPU 턴(이동 + 구매 + 건설 + 라운드 전환) 17.8–18.5초 → 19.9–21.6초,
  사람 턴 굴림 → 결정 6.1초 그대로. 읽기 쉬움을 우선해 비트를 줄이지 않았다.
- **검증**: 타입체크, 단위 테스트 509개(새 `beats.test.ts`: 모든 장면 ≥ 3.1초·0.7배 반복도 하한 유지·예비 동작 ≥ 0.5초·
  정지 ≥ 1초), 전체 브라우저 테스트 77개 통과(전체 실행 76 + 대기 시간을 늘린 1개 재실행), 웹 빌드 통과. 필름스트립을 보고
  각 장면의 포즈(시작, 동작, 결과, 1초 이상 정지)를 확인했다. 실기기 태블릿은 아직.
- **테스트할 때 볼 것**
  1. 구매·건설·통행료 컷인이 끝나기 전에 금액과 결과를 편하게 읽을 수 있는지(정지 화면 1초).
  2. 코인이 어디서 나와 어디로 가는지 하나씩 따라갈 수 있는지.
  3. 턴이 지루하게 길어졌다고 느껴지는지(게임 속도 설정으로 줄일 수 있는지).
