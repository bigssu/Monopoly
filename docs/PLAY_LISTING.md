### 5.1 Playwright 스크린샷으로 에셋 만들기

`npm run e2e` 는 `e2e/__screenshots__/` 에 Title, Setup, Game(중반부, 시드 고정), Result 화면을
1600x1000, 2560x1600, 1024x768, 800x450 크기로 저장합니다 (`docs/DESIGN.md` 8장). 이를 재료로 사용합니다.

1. **스크린샷 세트 뽑기**: 시드 고정 게임의 4개 화면 (타이틀 / 세팅 / 게임 중반 / 결과)을 기본으로 하고,
   가능하면 스테이지가 회전한 모습, 인수 스탬프, 축제 표시, 건물 상태 등 게임의 특징이 보이는 장면을 추가로 캡처합니다.
   e2e 스크립트에서 `page.screenshot({ path, type: 'png' })` 를 호출하는 장면을 늘리거나, 별도의 `e2e/store-shots.spec.ts` 를 만들어
   `viewport: { width: 2560, height: 1600 }` (10인치), `{ width: 1920, height: 1200 }` (7인치), `{ width: 1920, height: 1080 }` (휴대전화)로 실행하세요.
2. **규격 맞추기**: Play는 알파 채널이 있는 PNG를 거부합니다. ImageMagick 예:

   ```bash
   # 알파 제거(흰 배경 합성) + 정확한 크기로 리사이즈
   magick e2e/__screenshots__/game-mid-2560x1600.png -background "#1E2A3A" -alpha remove -alpha off \
     -resize 2560x1600 store/tablet10-02-game.png
   # 24비트 JPEG 로 저장하려면 확장자를 .jpg 로
   ```

   (ImageMagick 6 이하는 `magick` 대신 `convert` 를 사용)
3. **피처 그래픽 1024 x 500**: 앱 색상 배경(`#1E2A3A`) 위에 LOT & ROLL 엠블럼(`src/content/icons/` 또는 `docs/assets/icon-sheet.png` 에서 잘라내기)과
   게임 화면 일부를 배치합니다. HTML 로 만들고 Playwright 로 캡처하면 폰트(Jua)와 색이 앱과 정확히 일치합니다.

   ```js
   // scripts/feature-graphic.mjs (예시)
   import { chromium } from '@playwright/test';
   const b = await chromium.launch();
   const p = await b.newPage({ viewport: { width: 1024, height: 500 } });
   await p.goto('file://' + process.cwd() + '/store/feature.html');
   await p.screenshot({ path: 'store/feature-1024x500.png' });
   await b.close();
   ```
4. **앱 아이콘 512**: 엠블럼 SVG 를 512x512 로 렌더링해 PNG 로 저장 (`npx playwright` 또는 ImageMagick/Inkscape). 배경은 꽉 채운 정사각형으로.
5. **문구 오버레이 (선택)**: 스크린샷 위에 짧은 한 줄 카피를 얹으면 전환율이 오릅니다. 예: "한 대의 태블릿, 네 명의 여행자",
   "내 차례엔 무대가 나를 향해 돌아요", "인수! 내 도시가 되었어요", "광고 없음 · 완전 오프라인".
   (타사 언급 금지, 글자는 Jua/Noto Sans KR 사용 — 둘 다 OFL 이라 상업적 이미지에 사용 가능)
6. 산출물은 `store/` 같은 폴더에 두되 용량이 크면 저장소에 커밋하지 말고 릴리스 아티팩트로 보관합니다.

### 5.2 스크린샷 구성 제안 (순서대로 8장)

1. 4명이 둘러앉은 게임 중반 화면 (자리별 패널이 각 방향을 향함)
2. 주사위 굴리기 + 무대가 현재 플레이어를 향해 회전하는 순간
3. 도시 구매 카드 / 건설 선택 (별장 -> 명소)
4. 인수 연출
5. 이벤트 카드 공개
6. 세계 19개 도시가 보이는 전체 보드
7. 세팅 화면 (사람/CPU 선택, 옵션)
8. 결과 화면 (자산 막대 그래프)
