# 12. 딜러 연기: 픽사 12원칙으로 다시 만든 음성·움직임 (2026-10-23)

오너 요청: "음성과 딜러 애니메이션이 픽사의 12원칙에 맞게 만들어지지 않았다. 감정 표현·속도·강약을 다 조절하고,
빠진 대사를 채우고, 영어 음성도 같이 만들고, 한영 전환을 쉽게."

## 1. 무엇이 문제였나 (이전 상태)

| 항목 | 이전 | 원칙 위반 |
|---|---|---|
| 몸 | 표정 그림을 즉시 교체만 함, 움직임 없음 | 예비 동작·찌그러짐/늘어남·후속 동작·호(arc)·과장 없음 |
| 입 | 음성과 무관하게 120 ms마다 talk-a/talk-b 교대, 음성 시작 350 ms 뒤에야 움직임 | 타이밍: 입이 소리보다 늦고 내용과 무관 |
| 표정 | 3·6프레임마다 기계적으로 끼워 넣음 | 포즈 투 포즈가 아니라 일정 간격 |
| 음성 감정 | 265줄 전부 같은 설정 하나(stability 0.35, style 0.6) | 상황별 연기 지시 없음 |
| 음성 속도 | 전부 같은 속도 | 잔소리는 빠르게, 설명은 천천히 같은 대비 없음 |
| 음성 강약 | 전부 −18 LUFS로 맞춤 | 속삭임과 외침이 같은 크기 |
| 대사 | 건물 파괴·무인도 대기·형기 만료·빚 청산·유찰·경매 입찰·무료 업그레이드·꽝 카드·노려 던지기 결과에 대사 없음, 자주 나오는 상황에 대사 1개뿐 | 반복이 많고 비어 있는 장면 |

## 2. 12원칙을 이 딜러에 적용한 방식

스프라이트는 13장(표정 11 + 입 2)으로 그대로 두고, 그 위에 변형(transform)과 시간을 입혔다.
몸은 자기 레이어(`.dealer-body`, 발 기준)만 움직이므로 무대는 다시 그려지지 않는다(성능 게이트 B 유지).

| 원칙 | 적용 (`src/ui/dealer/acting.ts`, `cadence.ts`, `Dealer.ts`) |
|---|---|
| 1. 찌그러짐과 늘어남 | 모든 키에서 scaleX × scaleY ≈ 1(부피 유지, 테스트 ±6 %). 착지에서 납작, 도약에서 길쭉 |
| 2. 예비 동작 | 모든 행동 앞에 반대 방향 동작(도약 전 웅크림, 가리키기 전 뒤로 젖힘). 음성과 말풍선은 예비 동작 뒤(`ANTICIPATION_MS` 120 ms)에 들어온다 |
| 3. 연출(staging) | 한 번에 하나: 몸이 먼저 감정을 보여 주고, 말풍선과 소리가 따라온다 |
| 4. 포즈 투 포즈 | 말하는 동안 표정 포즈는 숨 쉬는 구간(270 ms 이상 멈춤)에만. 단어 사이는 입만 닫힘 |
| 5. 후속·중첩 동작 | 모든 테이크가 휴식점을 지나쳤다 돌아온다. 말풍선은 몸보다 늦게 튀어나온다 |
| 6. 천천히 들어가고 나오기 | 키마다 이징(settle/in/inOut) |
| 7. 호 | 오르기와 기울이기를 같이 써서 직선이 아닌 곡선 경로 |
| 8. 보조 동작 | 입 모양(립싱크)이 몸의 테이크와 따로 움직인다 |
| 9. 타이밍 | 슬픔 900 ms(느림), 긴장 520 ms(빠른 떨림), 우승 900 ms(긴 정지). 입은 소리보다 1프레임 먼저 |
| 10. 과장 | 대사 우선순위로 크기 조절: 잔소리 0.45 → 결과 1 → 큰 사건 1.25 → 엔딩 1.4. 클수록 조금 더 길게 |
| 11. 입체감 있는 그림 | 그림은 그대로(이번 범위 밖) |
| 12. 매력 | 표정마다 성격 있는 동작(웃음은 두 번 통통, 놀람은 고전적인 "take") |

### 립싱크

`voice.ts`가 디코딩한 음성에서 1/30초 단위 RMS를 계산한다(파일 추가 없음). 그 줄의 90번째 백분위수 기준
0.55 이상 = talk-a(크게 벌림), 0.18 이상 = talk-b(작은 "오"), 그 아래 = 닫힘. 속삭임도 그 줄 기준이라 입이 움직인다.
한 프레임짜리 끊김은 반쯤 열린 채로 둔다. 팔을 드는 표정은 오너 피드백(2026-10-06) 상한 1.39회/초를 넘지 않는다
(`cadence.test.ts`).

## 3. 음성 연기 지시 (Eleven v4 오디오 태그)

조사 결과(출처는 §6): Eleven v4는 대괄호 태그로 감정·전달·속도를 지시한다(`[excited]`, `[whispers]`, `[slowly]`,
`[rushed]`, `[pause]`, `[laughs]`, `[sighs]`, `[gasps]`, 자유 서술 `[like a news anchor, urgent]`). 속도 슬라이더와 SSML은
없고 속도는 태그로 정한다. 태그는 해당 말 바로 앞에 두고, 감정이 바뀌는 곳에서 새 태그를 쓴다. stability를 낮추면 표현이
커지고 테이크마다 차이가 커진다.

- **상황별 지시**: `lines.ts`의 `ACT` 표. 모든 상황에 [감정, 속도] 태그와 음량(`soft` −21 / `mid` −18 / `loud` −15 LUFS)이
  있다(빠지면 테스트 실패). 대비가 핵심: 잔소리(`roll.nudge`, `cpu.thinking`)는 조용하고 빠르게, 조언은 느긋하고
  작게, 결과는 짧고 세게, 뉴스는 앵커처럼, 엔딩은 크게.
- **대사 안의 태그**: 감정이 중간에 바뀌는 대사는 문장 안에 태그(`[gasps] 세상에!`, `[sighs] 휴우`, `[whispers] 쉿…`).
  말풍선에는 태그가 보이지 않는다.
- 녹음 대본 = 지시 태그 + 대사(`DealerLine.say`). `voice-texts*.json`에는 이 대본이 기록되므로, 지시만 바꿔도
  다시 녹음해야 한다(테스트가 잡는다).

## 4. 새 대사 (35줄)

새 상황 13개: `card.noEffect`, `demolish.typhoon`, `demolish.quake`, `aim.hit`, `aim.miss`, `island.stay`,
`island.served`, `auction.bid`(전체 단계만), `auction.none`, `debt.settled`, `upgrade.pick` — 엔진 이벤트·프롬프트 중
대사도 소리도 없던 것. 자주 나오는데 대사가 1–2개뿐이던 상황에 대사 추가: 구매 불가, 건설 보류, 인수 권유/보류,
인수 성공, 복권, 벌금, 탈출, 축제, 세금, 기부, 매각, 자동 선택, 허브.

## 5. 녹음과 검수

- `node scripts/dealer/gen-voice.mjs --all`: 한국어(Krys)·영어(Liam) 300줄씩.
- `node scripts/dealer/check-voice.mjs`: 모든 테이크를 ElevenLabs 음성 인식(scribe_v1)으로 받아 적어 대사와 비교한다.
  다른 말을 하거나 단어를 빼먹거나 태그를 소리 내 읽은 테이크는 점수가 낮다. 낮은 것은
  `gen-voice.mjs --only <id,…>`로 다시 녹음한다.
- 사람 귀로 듣는 검수는 아직이다(특히 태그가 의도한 감정으로 들리는지).
